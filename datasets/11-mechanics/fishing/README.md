# Mechanic: fishing

Scenario family `fishing`: fake players `iwdissi_*` exercising this mechanic.

## In simple terms

The dataset tracks fishing mechanics using fake players named iwdissi_* across four runs with four world seeds. These runs recorded 179,320,032 random number events at 236 distinct draw sites. The most frequent activity was creating tunnels, which accounted for 69,412,486 draws. Other common activities included calculating vertical gradients and generating carvers, with 16,241,070 and 15,884,759 draws respectively.
